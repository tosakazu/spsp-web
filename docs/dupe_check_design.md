# 重複参加チェック (dupes/)

start.gg の大会の参加者から、同じ人が別のアカウントで申し込んでいないかを調べる運営ツール。ページは `site/dupes/index.html`、
計算は `site/js/dupe_check.js`、画面と通信は `src/pages/dupes.js`。テストは `tests/frontend/dupe_check.test.cjs` (データは架空)。

## 方針

- **ブラウザの中だけで動く。** 参加者と連携アカウントは start.gg から、出場記録は SPSP の公開データ (`players/<uid>.json` とまとめの
  `data/views/bundle/`) から読む。SPSP のサーバには何も送らない (使用記録 `tool_logs` も取らない)。
- 認証はほかの運営ツールと同じ (`js/startgg_manager.js`: start.gg でログイン / API キー)。その大会の管理者でなければ読み込まない
  (確かめ方は下位クラス作成と同じ: owner / admins / 自分が管理する大会の一覧)。
- 名簿の外のアカウント (参加していない別アカウントと Discord が同じ、など) は調べない。それには連携アカウントから SPSP の選手を引く
  索引が要り、ブラウザだけではできないため。

## 流れ

1. **参加者**: `event.entrants` を 100 人ずつ (連携アカウント込みで start.gg の 1 回の上限 1000 件に収まる最大。150 人は断られる)。
   1,500 人の大会で 16 回、20〜30 秒。
2. **連携アカウントの取り直し**: start.gg は 1 回の応答に**同じ Discord アカウントを持つ人が 2 人いると片方の `authorizations` を null に
   して返す** (2026-10-30 に確認)。空で返った人を `user(id)` で 10 人ずつ取り直し、まだ空なら 1 人ずつ取り直す。
3. **候補の組** (`findCandidates`):
   - 同じ名前: NFKC・小文字・カタカナ→ひらがな・記号と空白を除いて同じ。かなの名前と英字の名前はローマ字にして同じ (なつ / Natsu)。
   - 名前が 1 文字違い: 正規化した名前の編集距離 1 (どちらも 3 文字以上)。偶然が多いので画面では折りたたむ。
   - 同じ Discord アカウント (`externalId` が同じ)。
   - 連携アカウントの名前が同じ (種類は問わない。Discord の名前と X の名前が同じでもよい。正規化して 4 文字以上)。
4. **材料**: 候補に入った人だけ SPSP の選手レコードを読む (同時 6)。部門ごとの勝敗 (`wins` / `losses`)・DQ・日付、
   都道府県 (`data/tournament_prefectures.json`、選手は `data/player_prefectures.json` → 出場記録の多い県 → start.gg の location)。
   SPSP に記録の無い人だけ、start.gg の参加大会数を `user(id) { tournaments { pageInfo { total } } }` で 20 人ずつまとめて取る。
5. **判定** (`compare`)。上から順に決める:

   | 判定 | 条件 |
   |---|---|
   | 別人 | 同じ部門に両方が出て、どちらも試合をしている (DQ・不戦だけの部門は根拠にしない)。または同じ日に別の地方の大会で両方とも試合をしている |
   | 同一人物 | 同じ Discord アカウント (ID) がつながっている |
   | 可能性が高い | 連携アカウントの名前が同じ |
   | たぶん別人 | 両方に記録があり出ていた時期が重なっていて、主な地域か連携アカウントが違う。または記録の無い側があり、地域も連携アカウントも違う |
   | 判断できない | 出ていた時期が入れ替わっている (作り直しの可能性)、記録の無い側の Discord が 1 年以内に作られた、材料が少ない |

   「別人」の条件と「同じ Discord」が両方当てはまるときは別人のまま、警告を添える (他人のアカウントに自分の連携をつないだ例がある)。
   Discord アカウントを作った日は ID (snowflake) の上位ビットから計算する。
6. **出力**: 表 (判定と決め手) と組ごとのカード (両方のアカウント・根拠の大会)。既定では「別人」の組は隠す。
   印刷すると結果だけが出る (PDF にできる)。CSV は全部の組。

## 表示する情報

- 名前・Discriminator・地域・SPSP の出場歴・使用キャラ・連携アカウントの名前と Discord を作った年月。
  連携アカウントの名前は start.gg のプロフィールで見られるもの。Discord の ID は照合にだけ使い、表示しない。

## 限界

- 出場記録は SPSP の集計対象の大会だけ (オンライン大会・身内大会などは入っていない)。
- 名前の候補は正規化と 1 文字違いだけ。まったく違う名前で申し込んだ人は、連携アカウントが同じでなければ拾えない。
