# シード被り回避ツール — 大会運営者向けの説明

SPSP のシードツールには「被り回避最適化」ボタンがあります。これは
**SPSP の実力順で並べたシードを、順位の形をほぼ保ったまま少しだけ入れ替えて、
「同じ地域の人が同プールに固まる」「最近対戦したばかりの2人がまた序盤で当たる」を
なるべく減らす**機能です。この資料では「シードがどこまで動き得るのか」
「どんなペアを優先して離すのか」「中で何をしているのか」を説明します。

---

## 1. 前提: シード番号とプールの関係(蛇行配置)

プール分けは一般的な「蛇行(スネーク)」です。例えば 16 プールなら:

```
シード 1〜16 → 各プールの1番手(P1→P16 の順)
シード17〜32 → 各プールの2番手(折り返して P16→P1 の順)
シード33〜48 → 各プールの3番手(また P1→P16)
…以下同様
```

以降「**層**」= プールの何番手か、と呼びます。実力的な意味はほぼ層が持っていて、
「同じ層のどのプールにいるか」は対戦運の話です(3番手の人がプール2でもプール7でも
勝ち上がりの期待値はほぼ同じ)。最適化はこの性質を利用します。

## 2. シードはどこまで動き得るか(移動制約)

動きは2種類だけで、それぞれに固定の上限があります。

### 2.1 プール間の移動(層は変わらない)

同じ層の中で、別のプールの人と入れ替わります。動ける幅は層ごとに決まっています:

| 層(プール内順位) | 動けるプール数 |
|---|---|
| 1番手・2番手 | **0(完全固定)** |
| 3番手 | ±1 プール |
| 4番手 | ±2 プール |
| 5番手 | ±4 プール |
| 6番手 | ±8 プール |
| 7番手以降 | 倍々(実質プール数で頭打ち=どこへでも) |

下位ほど広く動かせる設計です。上位のプール配置は実力準拠の意味が強く、
下位は「どのプールの6番手か」に実力的な意味がほぼないためです。

### 2.2 プール内の移動(層が1つ変わる)

同じプールの中で、隣の順位の人と入れ替わります(=1回戦で誰と当たるかが変わる):

- プール内順位の**上位 1/4 は固定**(8人プールなら上位2人)
- それ以外は**上下1段まで**

### 2.3 制約の効き方(重要な性質)

- 上限はすべて「**最初の位置(SPSP 順の位置)からの距離**」で測ります。
  入れ替えを何万回繰り返しても、じわじわ遠くへ流れていくことはありません。
- 入れ替えは「**両者とも**自分の枠に収まる」場合しか行われません。
  片方だけ得をする玉突き移動はできません。
- 2種の移動を合成しても、シード**番号**の上では最大「2×プール数−1」までしか
  動きません(蛇行の折り返しで番号が大きく飛んで見えることがありますが、
  実体は「同じ層でプール移動」+「プール内で1段」以内です)。
- さらに番号ベースで直接制限したい場合は、上級者メニューの
  「**シード変位上限 ±**」に数字を入れると「シード番号で±10まで」のように縛れます。
  0 なら一切動きません。

**16プール・128人の大会での具体例**: シード1〜32(各プール1・2番手)は一切動きません。
シード33〜48(3番手)は隣のプールへの移動と、プール内で1段の上下のみ。
シード97以降(7番手〜)はどのプールにも行けますが、層は±1段までです。

## 3. 何を避けるのか — スコアの式

最適化は「被りスコア」を最小化します。まず2人組 (a,b) ごとの罰則:

```
ペア罰則 pp(a,b) = 1.0 × 地域(a,b) + 0.3 × 直近対戦(a,b)
```

### 3.1 地域成分

```
地域(a,b) = 1/√(その地域の出場人数)   …2人が同じ地域のとき。違えば 0
```

同じ地域の2人が同プールにいるとこの罰則がかかります。**出場者が少ない地域ほど重い**:

| その地域からの出場 | 罰則 |
|---|---|
| 2人 | 0.71 |
| 4人 | 0.50 |
| 16人 | 0.25 |
| 49人(例: 東京勢) | 0.14 |

「2人しかいない○○県の2人が同プール」はほぼ確実に解消され、
大所帯の地域は(プール数を超える分は物理的に不可避なので)均等に散らす、
という挙動がこの式ひとつから出てきます。
なお南関東(埼玉/千葉/神奈川/東京)は既定でまとめて1地域として扱います(設定で変更可)。

### 3.2 直近対戦成分(時間減衰 × 大会規模)

過去の対戦1試合ごとに:

```
1試合の重み = log2(大会の参加人数) × 時間減衰(経過日数)

時間減衰: 0〜30日=1.0 → 91日=0.5 → 半年=0.25 → 1年=0 (間は直線でつなぐ)
```

そのペアの罰則は**全対戦のうち一番重い1試合**の値です(既定)。
何十回対戦している常連カードでも回数では積み上がりません
(「回数も効かせたい」場合は設定で合算に変更できます)。

具体例(×0.3 した後の、実際に効く値):

| 対戦 | 計算 | 罰則 |
|---|---|---|
| 先月、256人大会で対戦 | 0.3 × 8 × 1.0 | **2.4** |
| 3ヶ月前、64人大会 | 0.3 × 6 × 0.5 | 0.9 |
| 半年前、32人の対戦会 | 0.3 × 5 × 0.25 | 0.38 |
| 11ヶ月前、128人大会 | 0.3 × 7 × 0.05 | 0.10 |
| 1年以上前 | — | 0 (完全に忘れる) |

### 3.3 ペア罰則の効き方 — 「同プールか」と「何回戦で当たるか」の2段階

§3.1〜3.2 で決まる pp(a,b) は「この2人を近づけたくない度」です。
実際にスコアへ効くのは**その2人が同じプールになったときだけ**で、
さらに同プール内での位置(=当たり得る最速の回戦)で上乗せが決まります:

```
別のプール →  罰則 0
同じプール →  pp(a,b) × (1 + 回戦倍率)

回戦倍率: 1回戦=1.0  2回戦=0.6  3回戦=0.4  4回戦=0.06  5回戦以降=0.02
```

「1」の部分が**同プールになったこと自体**の罰則(プール間)、
「回戦倍率」の部分が**早く当たること**の罰則(プール内)です。

例: pp = 2.4 のペア(先月の大規模大会で対戦)の場合:

| 配置 | 計算 | 罰則 |
|---|---|---|
| 別プール | — | **0** |
| 同プールだが4回戦の位置 | 2.4 × (1 + 0.06) | 2.5 |
| 同プールで1回戦当たり | 2.4 × (1 + 1.0) | **4.8** |

だから最適化は、まず**別プールに離す**(罰則が丸ごと消える=一番効く)ことを試み、
制約上それが無理なら**同プール内で当たりを遅らせる**(半分弱まで軽減)、という
2段構えになります。§2 の2種類の移動はちょうどこれに対応していて、
プール間移動が「同プールかどうか」を、プール内移動が「何回戦で当たるか」を変えます。
なお4回戦以降の再戦がほぼ許容(倍率0.06以下)なのは意図的で、
**お互い勝ち上がった末の再戦は良い再戦**、という思想です。

### 3.4 元の順位から動かすこと自体のコスト

```
ズレ罰則 = 0.001 × (シードが元順位から動いた数)²   …全員分を合算
```

2乗なので、±2 の微調整は 0.004(ほぼタダ)ですが、±20 は 0.4、±30 は 0.9 と
急激に重くなります。**大移動は「それで大きな被りが解消できるときだけ」**起き、
被り解消に貢献しない無意味なシャッフルは起きません。

## 4. どんなペアを離しやすいか

上の式をそのまま読むと優先順位が分かります。**離れやすい順**に:

1. **最近(〜1ヶ月)・大規模大会で対戦したペア**(罰則 ~2.4)
   — 実は少人数県の地域被り(0.71)より重い。「先週の公式大会で当たった2人」が最優先です
2. **出場者が少ない県の同プール被り**(0.5〜0.71)
3. **2〜3ヶ月前の中規模大会での対戦**(~0.9)
4. **大所帯地域の同プール被り**(0.14〜0.25) — 完全解消は不可能なので「均等に散らす」方向
5. **半年前の対戦・小規模対戦会だけの対戦**(~0.4 以下) — 他と競合したら後回し

**離れにくい(=そのまま残りやすい)もの**: 1年近く前の対戦、週次対戦会レベルの
小規模対戦のみのペア、勝ち上がらないと当たらない位置(4回戦以降)の再戦、
そして「離すには制約(§2)を超える移動が必要」なケース。残った被りは
すべて実行後のレポートに理由つきで表示されます。

## 5. 中では何をしているのか(ざっくり)

いわゆる AI ではなく、シンプルな**試行錯誤の自動化**です:

1. SPSP 順そのままの蛇行配置からスタート
2. 制約(§2)の範囲内で「2人を入れ替えてみる」
3. スコア(§3)が下がったら採用、上がったら基本やり直し
4. これを十数万回繰り返す

コツが2つ:
- **序盤はわざと悪い手も受け入れ、だんだん慎重にする**(焼きなまし法)。
  こうしないと「そこそこ良いけど行き止まり」の配置にハマるためです
- **独立に15回やり直して一番良い結果を採用**。同点なら「元順位からのズレが
  小さい方」を選ぶので、無駄に動いた解は選ばれません

## 6. 保証されていること

- **上位は動かない**: 各プールの1・2番手(シード上位 2×プール数)は完全固定
- **層は保たれる**: 全員プール内順位±1段まで。実力順の骨格は崩れない
- **同じ入力なら同じ結果**: 乱数のタネも固定なので再実行で同じシードが出ます
  (あとから再現・検証できます)
- **適用は手動**: 結果はプレビューとレポートで確認してから「適用」を押すまで
  start.gg には反映されません

## 7. 実行後のレポートの読み方

- **改善率**: 被りスコアがどれだけ減ったか
- **① プール間×地域**: 各プールの地域内訳。「分離できるはずなのに残った被り」は赤、
  人数的に不可避な分はグレー
- **② プール間×直近対戦**: 同プールに残った直近対戦ペア
  (最終対戦日・大会名・規模つき。表示は半年以内のもののみ)
- **③④ プール内**: 3回戦以内で当たる同地域ペア/直近対戦ペア
- **順位比較表**: 誰が元の何位からどのシードへ動いたか(±付き)

## 8. 気になるときに触るつまみ(上級者メニュー)

| やりたいこと | つまみ |
|---|---|
| シード番号ベースで移動を制限したい | シード変位上限 ±(例: 10) |
| 地域被り回避だけ/再対戦回避だけにしたい | 「地域被り」「直近対戦」チェックボックス |
| プール内の並び替えをさせたくない | 「プール内変動」チェックを外す(レポートは出ます) |
| 動きをもっと渋くしたい | 元順位ズレ重みを 0.001 → 0.01〜0.05 に |
| 常連ペアをより強く離したい | ペア集計を max → sum に(対戦回数も効くようになる) |
| 忘れる速さを変えたい | 時間減衰の制御点(「日:重み」のリスト)を編集 |

わからなければ全部デフォルトで大丈夫です。デフォルトは実大会のデータで
「序盤の直近再戦が半分〜1/3 になる」ことを確認して調整してあります。
